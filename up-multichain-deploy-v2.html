0 · Running locally

Browser extensions (UP, MetaMask) often do not inject into a page opened straight from disk (file://). You need a small local server — it only runs on your machine.
Open a terminal in the folder where you saved this file:
python3 -m http.server 8000 --bind 127.0.0.1
If python3 is not installed (check with python3 --version), with Node.js you can use:
npx serve -l tcp://127.0.0.1:3000 .
Then open http://localhost:8000/ (or the URL printed by npx serve) — not file://.
